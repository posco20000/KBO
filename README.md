# AI Contest Korea — Simple

대한민국 AI 공모전 정보를 검색하고 접수 상태별로 확인할 수 있는 간결한 단일 페이지 웹사이트입니다.

## 주요 기능

- 공모전명, 주최기관, 참가 대상 통합 검색
- 접수 중, 마감 임박, 모집 예정 필터
- 공식 공고 바로가기
- 모바일과 데스크톱 반응형 화면

## 실행

```bash
pnpm install
pnpm dev
```

프로덕션 빌드는 `pnpm build`로 생성합니다.

## 참고

공모전 정보는 2026년 8월 20일 기준이며, 신청 전 반드시 연결된 공식 공고에서 최신 일정을 확인하세요.
